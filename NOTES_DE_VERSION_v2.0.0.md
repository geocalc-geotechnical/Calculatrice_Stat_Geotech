## GeoCalc 2.0.0

Première version publique : version gratuite + version PRO.

### Gratuit, sans limite de données
- Import CSV, Excel ou copier-coller (virgule française, titres avant l'en-tête, séparateurs de milliers)
- Valeurs aberrantes (Grubbs, Dixon, Chauvenet, IQR), lois de distribution, valeurs caractéristiques Eurocode 7, régressions

### PRO (clé de licence, activation hors ligne)
- Comparaison de groupes, variabilité spatiale et krigeage, fiabilité (FORM, Monte-Carlo, bayésien)
- Synthèse par couche, rapports Word / PDF / Excel, projets enregistrables

### Installation
Décompressez **entièrement** l'archive, puis lancez `GeoCalc.exe` (Windows 10 / 11, 64 bits). Si Windows SmartScreen s'affiche : « Informations complémentaires » ▸ « Exécuter quand même ».
